# Python Version
# Requires Python 3.9 or higher

# Core Dependencies (from requirements.txt)
# Install with: pip install -r requirements.txt

# System Dependencies (need to be installed separately):
# 
# For pdf2image:
# - Windows: Install poppler (download from http://blog.alivate.com.au/poppler-windows/)
# - Linux: sudo apt-get install poppler-utils
# - macOS: brew install poppler
#
# For pytesseract:
# - Windows: Install Tesseract OCR from https://github.com/UB-Mannheim/tesseract/wiki
# - Linux: sudo apt-get install tesseract-ocr
# - macOS: brew install tesseract
#
# For PostgreSQL (if using PostgreSQL instead of SQLite):
# - Install PostgreSQL server
# - Create database: createdb certify_db

# Optional: Virtual Environment Setup
# python -m venv venv
# Windows: venv\Scripts\activate
# Linux/Mac: source venv/bin/activate

# Install all dependencies:
# pip install -r requirements.txt

# For development:
# pip install -r requirements-dev.txt
